# Textify

Textify is a publishable React/Vite app for creating animated text effects and exporting them as SVG, HTML, or WebM.

## Run locally

```bash
npm install
npm run dev
```

## Publish

Build the static site:

```bash
npm run build
```

Upload the generated `dist` folder to any static host, or use these settings:

- Build command: `npm run build`
- Publish directory: `dist`
